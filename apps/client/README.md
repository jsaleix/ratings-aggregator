# Movie Ratings Aggregator Client

## Stack

| Category | Technologies |
| -------- | ------------ |
| Language | TypeScript |
| Framework | React + Vite |
| Styling | TailwindCSS |
| Data fetching & Forms | TanStack Query & Form |
| Validation | Zod |
| Animations | Motion |
| Carousel | React Slick |
| Component docs | Storybook |
| Testing | Vitest + Testing Library |

## Scripts available

| Command               | Description                                   |
| --------------------- | --------------------------------------------- |
| `pnpm install`        | Install project dependencies                  |
| `pnpm run dev`        | Start the Vite dev server with hot module replacement |
| `pnpm run test`       | Run unit tests                                |
| `pnpm run test:watch` | Run unit tests in watch mode (re-runs on file changes) |
| `pnpm run build`      | Compile and bundle the app for production via Vite |
| `pnpm run preview`    | Serve the production build locally to preview before deployment |

## Documentation

Storybook components documentation available by running `pnpm run storybook`.
